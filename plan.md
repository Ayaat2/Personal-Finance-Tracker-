# 💰 Personal Finance Tracker

A simple and interactive Personal Finance Tracker that helps users manage their income and expenses in one place, visualize their budget, and track their financial health in real-time.

## 🎨 UI Components
 - [x] Income input field
 - [x] Summary section (total expenses + remaining balance)
 - [x] Expenses list container
 - [x] Single expense item:
   - [x] Expense name (editable)
   - [x] Expense amount
 - [x] Delete button
 - [x] Drag handle
 - [x] Add expense form (name + amount)
 - [x] Pie chart container
 - [x] Export button
 - [x] Empty state (when no expenses)
 - [x] Responsive layout (mobile & desktop)

## ✅ Features
 - [x] Real-time budget calculation (income, expenses, balance)
 - [x] Instant UI updates on user input
 - [x] Interactive pie chart visualization
 - [x] Add new expense items
 - [x] Delete expense items
 - [x] Edit expense names (contenteditable)
 - [x] Drag & drop to reorder expenses
 - [x] Data persistence using Local Storage
 - [x] Export chart as image (PNG, JPEG, SVG)
 - [x] Responsive design for all screen sizes
